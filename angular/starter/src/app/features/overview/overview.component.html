Build native experiences inside Identity Security Cloud

Your plugin renders as a micro-frontend right inside Identity Security Cloud. It rides the tenant's session and security model, so there is no separate login, no external hosting, and nothing extra to secure.

What can you build?

  • Dashboards that bring together data from any Identity Security Cloud API
  • One-click workflow launchers that kick off your business processes
  • Admin tools tuned to your organization's governance needs

The pages in this template show the patterns you will use every day: reading plugin context, calling Identity Security Cloud APIs with typed SDK services, and launching workflows through the Launchers API.

Getting started

This template is yours to reshape. The SDK wiring in core/ handles the App Shell handshake, so components simply read signals and call services. Open the Workflows tab to see how to list and start launchers, and the API Examples tab for the Observable and Promise patterns when calling Identity Security Cloud APIs.
