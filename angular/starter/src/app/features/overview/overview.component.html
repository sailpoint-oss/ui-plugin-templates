Welcome to Your UI Plugin

This plugin runs inside Identity Security Cloud as a micro-frontend. It uses the tenant's session and honors its security model, so there is no separate authentication and no external hosting.

What can you build?

  • Custom dashboards that surface data from multiple ISC APIs
  • Workflow launchers that let users trigger business processes with one click
  • Administrative tools tailored to your organization's governance needs

The pages in this template demonstrate the patterns you will use: reading plugin context, calling ISC APIs with typed SDK services, and launching workflows through the Launchers API.

Getting started

Replace this content with your own UI. The SDK integration in core/ handles the App Shell handshake. Components read signals and call services. The Workflows tab shows how to list and start launchers. The API Examples tab demonstrates Observable and Promise patterns for calling ISC APIs.
