API Examples

The SailPoint Angular SDK provides typed services for calling ISC APIs. This page demonstrates two patterns: Observable (for reactive pipelines and template binding) and Promise (for event handlers and sequential chains).

Observable Pattern

IdentitiesService.listIdentitiesV1() returns an Observable. Use it with AsyncPipe for automatic subscription management. A gate signal controls when the Observable is subscribed.

Prefer Observables when: binding results directly to templates, chaining multiple async operations reactively, or when you need cancellation on component destroy.

Promise Pattern

TenantService.getTenantV1() wrapped with firstValueFrom() converts the Observable to a Promise. Useful for event handlers and async/await chains.

Prefer Promises when: responding to user actions in event handlers, writing sequential async logic, or integrating with Promise-based libraries.
